**Trigger:** Driving the Market Settings "Languages and currencies" tab: adding a currency through "Assign currency" and removing one through the row action, then saving and reading the backend response.

**Rule:** Picker: focus the input with placeholder "Assign currency", set the value via the native setter, dispatch `input`, wait ~600 ms, then click the visible `[role="option"]`/`li` whose trimmed text EQUALS the code (`'EUR'`). A loose regex such as `/EUR|Euro/i` also matches the sidebar item "Connections" and clicks it (harmless but no add). Row removal: the `find` ref for "Remove currency" only reveals the red ⊗ (hover state); click it again by coordinate at the row's right edge (~x 1302) and confirm with a `zoom` that the row is gone. Save: the top SAVE by coordinate can no-op while the picker has focus; use the `find` ref for "Save". Capture the result with the fetch hook on `POST /admin/multi-shop/market-settings/submit/` (module-off add → 422 `formErrors.currencies`, unchanged echo → 200) and never trust the toast alone; the success toast auto-hides within seconds.
