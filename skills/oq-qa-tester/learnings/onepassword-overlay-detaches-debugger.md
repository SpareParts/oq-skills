**Trigger:** `computer:type` into an admin text input fails with "Debugger is not attached to the tab" or every subsequent tool call fails with "Cannot access a chrome-extension:// URL of different extension" (1Password overlay stole the debugger target).

**Rule:** Two failure modes. Mild: the typed text usually landed — screenshot to confirm and continue. Hard (extension-URL error on every call, including screenshot/JS): nothing landed and the session is stuck on the extension target — recover with a `navigate` call to the same URL (resets the debugger target; wizard state is lost). Prevention: avoid `computer:type` on admin text inputs entirely — set values via JS native setter + `input`+`change`+`blur` events (see react-wizard-js-fill-not-committed for why all three).
