**Trigger:** After filling a React admin form/wizard, `navigate` fails with `Navigation was blocked by a "Leave site?" dialog … retry with force: true`, and `tabs_close_mcp` on that tab times out with the generic "did not respond in time" error.

**Rule:** The `force: true` the error message suggests is NOT in the `navigate` schema this harness loads, so the retry it proposes cannot be made; `window.onbeforeunload = null` plus clearing the input does not disarm it either (React's `useLeavePrompt` registers a listener, not the `onbeforeunload` property). The tab is then unusable AND unclosable — the close attempt parks a native dialog that only the user can dismiss. Work around it, don't fight it: `tabs_create_mcp` a fresh tab and continue there, close the clean tabs normally, and report the dirty one as left open for the user to close. Prevention: keep one throwaway tab for form-dirtying flows and do all later navigation from a second tab, and prefer `leave-prompt-synthetic-probe`'s `dispatchEvent` check over anything that actually navigates a dirty page.
