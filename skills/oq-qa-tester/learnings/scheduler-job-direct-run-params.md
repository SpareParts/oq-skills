**Trigger:** A scenario needs a scheduler job run locally WITH input arguments (e.g. `dryRun=1`), or `st-scheduler-job` is "not found" from `./docker/dev ai console`.

**Rule:** The wrapper lives at `/shoptet-src/scripts/st-scheduler-job` inside the `console` (and `supervisor`) container and is not on the PATH of `./docker/dev ai console`; run it as `./docker/dev compose exec -T console sh -c 'cd /shoptet-src/cms4 && /shoptet-src/scripts/st-scheduler-job -o "dryRun=1" <PROJECT_ID> <JOB_ID>'`. `-o PARAMS` is appended as `argv[5]` for direct runs too (not only when enqueuing); the format is newline-separated `key=value` (`StandardHelper::parseParamSettings`), so several params need `-o "a=1\nb=2"` (the wrapper runs `echo -e`). The script path is `/var/www/src/cms4/master/current/cms/schedulerJob.php`, a symlink to `/shoptet-src/cms4`, so the job executes the checked-out branch. Jobs with `projectPreset NULL` and no `scheduler_projects` rows still run for any project id you pass (2026-09-17: job 5810 `ProjectDomainSyncJob`). Exit code is always 1 (see scheduler-job-wrapper-exit-code-always-1); read the summary line from stdout.
