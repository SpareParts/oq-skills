**Trigger:** Proving that a write fired when the written value is unchanged — e.g. a PR moves an option write out of an `if (changed)` branch and you must show it now runs on every save.

**Rule:** Count the log line instead of diffing the value. `OptionsHelper::validateWriteOptionVariants()` (`cms/packages/Miscellaneous/Helper/OptionsHelper.php:827`) logs `[Sales Channel] Option is being set with unsupported variant` for any per-channel or per-language write of an option whose `options.perSalesChannel` / `perLanguage` flag is 0. Baseline with `./docker/dev compose exec -T www sh -c 'grep -ac "Option is being set with unsupported variant" /var/www_logs/php/php_events_json.log'`, act, re-count, then read the last entry's `context.indexName` / `context.salesChannelId` and `extra.request` to attribute it. Only works for scoped writes (a global write has `salesChannelId` NULL and logs nothing), and only while the flag stays 0 — which is itself worth reporting: on 2026-09-17 `default_language_code_frontend` had `perSalesChannel = 0` on every project while the code stored 30 channel-scoped rows.
