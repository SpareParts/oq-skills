**Trigger:** Deleting a row on the React Domain redirections list (`/admin/dns-presmerovani/?id=<marketId>`), or any React admin DataGrid whose row action icons are hidden until hover.

**Rule:** `find` returns the "Smazat položku" button ref, but a ref click on the hidden icon only triggers the hover state (the red ⊗ appears at the row's right edge) and does NOT open the dialog. Click again by COORDINATE on the now-visible icon; the confirmation is a React ConfirmModal ("Jste si jistí? Přesměrování domény přestane fungovat okamžitě.") with ZRUŠIT/OK — safe for CDP, confirm via the OK ref. The action is a `fetch` `DELETE /admin/dns-redirection/delete/` (200 `{"code":200,"message":"OK"}`), capturable with the window.fetch hook, followed by the notifier "Záznam byl úspěšně odstraněn." and the row disappearing without a reload. Refs go stale after the list re-renders — re-`find` before the next row.
