**Trigger:** Re-checking a React admin page (Market Settings, currency detail) after mutating its data through an endpoint, to prove the UI reflects the DB.

**Rule:** `navigate` to the page's current URL, with or without the tab `#fragment`, is a same-document navigation in Chrome: no request is made and the stale DOM stays (observed 2026-09-10: DB said SEK, page still showed Koruna after a "reload"). Force a real load with a throwaway query param (`?id=89&qa=s2`), which the React pages ignore, and if the form holds rejected values use `force: true` on the navigate to discard the "Leave site?" dialog. A coordinate click on a tab right after the navigate races hydration (lands on the Settings tab); wait ~3 s, `find` the tab and click its ref, then `scroll` 5 ticks before the screenshot to get the Currency table in frame.
