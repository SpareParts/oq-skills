**Trigger:** Verifying a dirty-form leave prompt on a React admin page (`useLeavePrompt` via `useForm`'s `leavePrompt`) without freezing CDP on a native dialog.

**Rule:** Two native-dialog paths exist: `beforeunload` (reload/close/full-page nav) and an Inertia `router.on('before')` hook that calls native `confirm()` on in-app visits — clicking any nav link while dirty blocks CDP. Probe instead: `!window.dispatchEvent(new Event('beforeunload', {cancelable:true}))` returns `true` when the prompt is armed (handler calls preventDefault) and `false` when not. Test matrix: dirty → true; after successful ajax save → false (`useForm` runs `reset(values, {keepValues:true})` on success). Note the RHF baseline is the MOUNT-time defaults — a refetch does not reset them, so "restore the on-screen values" may not clear dirty; reload the page when a clean baseline is needed.
