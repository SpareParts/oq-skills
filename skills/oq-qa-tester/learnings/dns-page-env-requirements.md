**Trigger:** `/admin/dns/?id=<marketId>` (MultishopDnsSettings) renders the generic "A safra! Něco se pokazilo." page on a dev shop.

**Rule:** Two env preconditions, both usually unmet locally: (1) `st_cms.scheduler` row `code='dnsValidation'` must have `visible=1` — an unguarded `SchedulerBackgroundRunner::getJobIdForJobCode` call site throws otherwise; (2) a market with a custom domain needs a `dns_validation_results` snapshot row (st_<projectId>), else the React page crashes on `null.date`. For disconnect-domain scenarios, skip the page and POST `/admin/multi-shop/disconnect-domain-from-market/` with `{"id": <marketId>}` from the logged-in tab — that is exactly what the button does.
