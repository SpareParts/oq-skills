**Trigger:** Driving the v2 create-market wizard (`/admin/pridat-online-obchod-v2/`) down the "Mám vlastní doménu" branch on a dev shop — the "Metoda přesunu domény" and "Kontrola nastavení" steps render completely empty (no domain input, no submit control, no console error).

**Rule:** The custom-domain UI is env-blocked locally (same family as dns-page-env-requirements). Drive `POST /admin/multishop/create-market-wizard/submit/` directly from the logged-in tab instead. The submit validator requires a `dns_validation_results` snapshot row in `st_<projectId>` for the typed domain: seed `(domain=<bare host>, type='basic', isValid=1, validatedAt=NOW())` with `result` = `{"type":"basic","payload":{"domain":"<bare host>","setupMethod":"core_records","withEmail":false,"entries":[]}}` — empty `entries` makes `isValid()` true, and `payload.setupMethod` must equal the request's `domainSetupMethod`. Payload shape: `{domainAndName:{name,domainSetupMethod,domain,isDomainValid},deliveryCountries:{existingDeliveryCountries:[id],newDeliveryCountries:[],primaryDeliveryCountryId:id},currencies:{existingCurrencies:['CZK'],newCurrencies:[],primaryCurrencyCode:'CZK'},languages:{existingLanguages:['cs'],newLanguages:[],primaryLanguageCode:'cs'}}` (CZ country id in `cms2_codebook_countries` = 43).
