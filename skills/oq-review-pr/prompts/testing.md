## Your assigned dimension: Testing

- Are new features/behaviors covered by tests?
- Are edge cases tested, such as null inputs, empty arrays, error paths, and permission
  boundaries?
- Do test names describe behavior clearly?
- If source files changed but no tests were added or modified, decide whether that is
  justified.
- Are tests proving the behavior that matters, or only exercising implementation
  details for coverage?
- Prefer FixtureBuilders over ad-hoc fixture creation where the repository has such
  patterns.
